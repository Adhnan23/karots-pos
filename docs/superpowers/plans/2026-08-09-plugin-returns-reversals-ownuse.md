# Plugin returns / reversals + own-use Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add reversal of recharge reloads (failed vs wrong-number) and documents jobs (mistaken → loss), plus own-use recording for documents, entirely in the plugins — with one additive exposure of the core stock service and no change to core business logic.

**Architecture:** The original core sale is never mutated (core forbids service-line returns). Each reversal posts *compensating* moves through already-exposed core services (`CashRegister`, `Expenses`, `Stock`, `Audit`) and the plugin's own tables. Whether the cash-out is a plain `Withdraw` (no loss) or is paired with an `Expense`/left-unrecovered (a loss) is chosen so the P&L nets correctly with no new loss-tracking machinery. UI reversals live on the existing `ReceiptTab` hook surfaces.

**Tech Stack:** Go, Echo, templ, HTMX/Alpine, PostgreSQL 17, goose migrations, sqlx, shopspring/decimal. Single static binary (`go:embed`).

## Global Constraints

- No changes to core business logic (sales, returns, stock, P&L). The ONLY core edit is adding `Stock *stock.Service` to `internal/plugin/core.go` and wiring it in `internal/web/web.go`.
- No new plugin hook *types* — use the existing `ReceiptTab` hook for surfaces.
- Each plugin's migrations run under its own goose version suffix (recharge → `goose_db_version_recharge`, documents → `goose_db_version_documents`). Migrations are additive only.
- `*_templ.go` files are generated by `make build`/`templ generate` and are gitignored — never hand-edit or commit them. Edit the `.templ` source.
- DB-guarded tests skip when `DATABASE_URL` is unset, run inside a rolled-back tx, and use far-future dates / high literal ids so no real dev data is in range (mirror `plugins/recharge/earnings_test.go`).
- `money.Parse` parses decimal strings; amounts are `decimal.Decimal`.
- Reversal amount refunded to the customer = the reload face `amount` (reloads carry no per-reload service fee) / the documents job `line_total`.
- Run `set -a && . ./.env && set +a` before running the server or DB tests so `DATABASE_URL` and `POS_SUPPORT_SECRET` are set. Dev server on `:3000`; admin `0771234567`/`1234`, cashier `0771111111`/`1111`. Dev `pos_db` is disposable — tidy up after live tests.

- [ ] **Step 5: Implement `reverseReloadTx` (+ exported `ReverseReload`)**

In `plugins/recharge/recon.go`:

```go
// reverseReloadTx reverses a reload within a caller tx: it guards that the target
// is an un-reversed reload, inserts the compensating reversal transaction, and
// stamps the original. mode "failed" returns the float (+amount); "wrong_number"
// leaves it gone (float_delta 0) — the loss is already carried by the un-recovered
// refill expense. It moves NO drawer cash; the handler does that.
func (s *Store) reverseReloadTx(ctx context.Context, q appdb.Queryer, reloadTxID int64, mode string, userID int64) (int64, error) {
	var orig struct {
		SessionID  int64           `db:"session_id"`
		CarrierID  int64           `db:"carrier_id"`
		DeviceID   int64           `db:"device_id"`
		Type       string          `db:"type"`
		Amount     decimal.Decimal `db:"amount"`
		ReversedAt *time.Time      `db:"reversed_at"`
	}
	if err := q.GetContext(ctx, &orig, `
		SELECT session_id, carrier_id, device_id, type, amount, reversed_at
		FROM recharge_transactions WHERE id=$1 FOR UPDATE`, reloadTxID); err != nil {
		if errors.Is(err, sql.ErrNoRows) {
			return 0, errors.New("reload not found")
		}
		return 0, err
	}
	if orig.Type != "reload" {
		return 0, errors.New("only reloads can be reversed")
	}
	if orig.ReversedAt != nil {
		return 0, errors.New("this reload was already reversed")
	}
	revType := "reversal"
	if mode == "wrong_number" {
		revType = "reversal_lost"
	} else if mode != "failed" {
		return 0, errors.New("unknown reversal mode")
	}
	note := "reversal of reload #" + strconv.FormatInt(reloadTxID, 10) + " (" + mode + ")"
	revID, err := s.RecordTransactionTx(ctx, q, TxInput{
		SessionID: orig.SessionID, CarrierID: orig.CarrierID, DeviceID: orig.DeviceID,
		Type: revType, Amount: orig.Amount, Note: note, CreatedBy: userID,
	})
	if err != nil {
		return 0, err
	}
	if _, err := q.ExecContext(ctx,
		`UPDATE recharge_transactions SET reversed_at = NOW(), reversal_of = $2 WHERE id = $1`,
		reloadTxID, revID); err != nil {
		return 0, err
	}
	return revID, nil
}
```

Note: `reversal_of` on the *original* points to the reversal row (marks it reversed and links the pair); the reversal row's own `reversal_of` stays NULL. Guarding on `reversed_at IS NULL` (via `FOR UPDATE`) is what blocks double reversal.

```go
// ReverseReload refunds the customer and reverses the float. Failed → float
// returns; wrong-number → float stays gone (loss already carried by the refill
// expense). Requires an open drawer (the refund is drawer-guarded).
func (h *cashierUI) ReverseReload(c echo.Context) error {
	ctx := c.Request().Context()
	uid := middleware.CurrentUserID(c)
	if _, err := h.requireSession(c); err != nil {
		return err
	}
	id, err := strconv.ParseInt(c.Param("id"), 10, 64)
	if err != nil || id <= 0 {
		return apperr.BadRequest("invalid reload id")
	}
	mode := c.FormValue("mode") // "failed" | "wrong_number"
	if mode != "failed" && mode != "wrong_number" {
		return apperr.Validation("choose what happened")
	}
	orig, err := h.p.store.TxByID(ctx, id)
	if err != nil {
		return apperr.NotFound("reload")
	}
	if orig.Type != "reload" {
		return apperr.BadRequest("only reloads can be reversed")
	}
	reason := orig.Carrier + " reload reversal #" + strconv.FormatInt(id, 10)
	// 1) Refund the customer from the drawer (guards against the drawer balance).
	if _, err := h.p.core.CashRegister.Withdraw(ctx, uid, cashregister.MovementInput{
		Amount: orig.Amount.String(), Reason: reason,
	}); err != nil {
		return err
	}
	// 2) Reverse the float in one DB tx.
	var revID int64
	if err := appdb.WithTx(ctx, h.p.core.DB, func(tx *sqlx.Tx) error {
		revID, err = h.p.store.reverseReloadTx(ctx, tx, id, mode, uid)
		return err
	}); err != nil {
		return err
	}
	_ = revID
	h.p.core.Audit.Log(c, audit.ActionUpdate, "recharge_reload", id, "reversed ("+mode+")")
	return h.reconFragment(c, response.Toast("Reload reversed & refunded", "success"))
}
```

Import `appdb "karots-pos/internal/db"`, `"github.com/jmoiron/sqlx"`, `"karots-pos/internal/features/cashregister"`, `"karots-pos/internal/features/audit"` as needed.

Ordering note: the refund `Withdraw` commits its own drawer movement before the reversal tx. If the reversal tx then failed (e.g. already reversed), the guard in Step-2 of Task 2 runs first for the common case, but to be safe the handler re-checks nothing after Withdraw — so re-verify `reversed_at IS NULL` is enforced by `FOR UPDATE` and that the double-reverse path is blocked by the `ReverseReloadForm`/button only showing on un-reversed rows. 		`SELECT reversed_at IS NOT NULL FROM recharge_transactions WHERE id=$1`, id); err != nil {
		return apperr.NotFound("reload")
	}

	}
```

type JobFilter struct {
	From, To *time.Time
	Limit    int
}

// RecentJobs lists sale jobs (kind='sale') newest first for the receipts tab.
func (s *Store) RecentJobs(ctx context.Context, f JobFilter) ([]Job, error) {
	lim := f.Limit
	if lim <= 0 { lim = 100 }
	var rows []Job
	err := s.db.SelectContext(ctx, &rows, `
		SELECT * FROM doc_job
		WHERE kind = 'sale'
		  AND ($1::timestamptz IS NULL OR created_at >= $1)
		  AND ($2::timestamptz IS NULL OR created_at <  $2)
		ORDER BY id DESC LIMIT $3`, f.From, f.To, lim)
	return rows, err
}

func (s *Store) JobByID(ctx context.Context, id int64) (*Job, error) {
	var j Job
	if err := s.db.GetContext(ctx, &j, `SELECT * FROM doc_job WHERE id=$1`, id); err != nil {
		return nil, err
	}
	return &j, nil
}

func (s *Store) MarkJobReversedTx(ctx context.Context, q appdb.Queryer, id int64) error {
	res, err := q.ExecContext(ctx, `UPDATE doc_job SET reversed_at = NOW() WHERE id=$1 AND reversed_at IS NULL AND kind='sale'`, id)
	if err != nil { return err }
	if n, _ := res.RowsAffected(); n == 0 {
		return errors.New("job not found or already reversed")
	}
	return nil
}
```

// ReverseJob refunds the customer and books the wasted paper as a loss: the refund
// is a drawer withdrawal, and a matching expense contras the sale revenue, leaving
// the already-consumed paper COGS as the loss. Stock is untouched (paper is gone).
func (h *cashierUI) ReverseJob(c echo.Context) error {
	ctx := c.Request().Context()
	uid := middleware.CurrentUserID(c)
	id, err := strconv.ParseInt(c.Param("id"), 10, 64)
	if err != nil || id <= 0 {
		return apperr.BadRequest("invalid job id")
	}
	j, err := h.p.store.JobByID(ctx, id)
	if err != nil {
		return apperr.NotFound("job")
	}
	if j.Kind != "sale" || j.ReversedAt != nil {
		return apperr.Conflict("this job can't be reversed")
	}
	reason := "Print & Copy reversal #" + strconv.FormatInt(id, 10)
	desc := j.Description
	// 1) refund the customer from the drawer (guarded)
	if _, err := h.p.core.CashRegister.Withdraw(ctx, uid, cashregister.MovementInput{
		Amount: j.LineTotal.String(), Reason: reason,
	}); err != nil {
		return err
	}
	// 2) contra the sale revenue with an expense; the paper COGS remains the loss
	if _, err := h.p.core.Expenses.Create(ctx, expenses.CreateInput{
		Category: "Print & Copy — mistaken job",
		Amount:   j.LineTotal.String(),
		Description: &desc,
	}, uid); err != nil {
		return err
	}
	// 3) mark reversed
	if err := appdb.WithTx(ctx, h.p.core.DB, func(tx *sqlx.Tx) error {
		return h.p.store.MarkJobReversedTx(ctx, tx, id)
	}); err != nil {
		return err
	}
	h.p.core.Audit.Log(c, audit.ActionUpdate, "documents_job", id, "reversed (mistaken job)")
	return response.RenderFragment(c, response.Toast("Job reversed & refunded", "success"))
}
```

// OwnUse records a no-cash shop-use job: it consumes each paper/consumable
// component as own_use (same P&L line products use) and logs a kind='own_use'
// doc_job. No customer, no drawer move, no receipt.
func (h *cashierUI) OwnUse(c echo.Context) error {
	ctx := c.Request().Context()
	uid := middleware.CurrentUserID(c)

	sid, _ := strconv.ParseInt(c.FormValue("service_id"), 10, 64)
	size := c.FormValue("size")
	color := truthy(c.FormValue("color"))
	double := truthy(c.FormValue("double_side"))
	qty, err := strconv.Atoi(c.FormValue("qty"))
	if err != nil || qty <= 0 {
		return apperr.Validation("quantity must be positive")
	}
	sv, err := h.p.store.ServiceByID(ctx, sid)
	if err != nil {
		return apperr.NotFound("service")
	}

	// Resolve components exactly as Quote/Record do (paper whole-units + core recipes).
	comps, consCost := h.resolveComponents(ctx, sv, size, double, qty) // extract this shared helper from Quote

	// Consume each component as own_use.
	for _, cm := range comps {
		if err := h.p.core.Stock.Consume(ctx, stock.ConsumeInput{
			ProductID: cm.productID,
			Quantity:  cm.qty.String(),
			Reason:    "own_use",
			Note:      "Print & Copy shop use: " + buildDesc(sv.Name, size, color, double, qty),
		}, uid); err != nil {
			return err
		}
	}
	sidPtr := sid
	if err := h.p.store.InsertJob(ctx, Job{
		ServiceID:      &sidPtr,
		Description:    buildDesc(sv.Name, size, color, double, qty),
		Qty:            decimal.NewFromInt(int64(qty)),
		UnitPrice:      decimal.Zero,
		LineTotal:      decimal.Zero,
		ConsumableCost: consCost,
		Kind:           "own_use",
	}); err != nil {
		return err
	}
	h.p.core.Audit.Log(c, audit.ActionCreate, "documents_ownuse", sid, buildDesc(sv.Name, size, color, double, qty))
	return response.RenderFragment(c, response.Toast("Shop use recorded", "success"))
}
```
